# UI / UX design system

Source: UI UX Pro Max token architecture (primitives → semantic aliases → components).

Product feel: operational, dense enough for dispatchers, calm navy/teal, no decorative gradients.

- Font: IBM Plex Sans
- Primary: navy `#163a66`
- Accent: teal `#0f766e`
- Warning/money attention: amber
- Radius: 6–8px
- Touch targets: 44px
- Mobile: bottom nav, cards instead of tables, FAB create
- States: loading, empty, error, permission denied on every major view
- Print: hide chrome

Tokens: `frontend/src/styles/tokens.css`
